## Android — run it in Android Studio

### 1. Prerequisites (one-time, on your machine)
- **Android Studio** (latest stable) with the Android SDK installed via its SDK Manager
- **Node.js 18+**
- A configured **Android Virtual Device (AVD)** — Android Studio's Device Manager can create one (e.g. Pixel 7, API 34)

### 2. Install JS dependencies
```bash
cd mobile
npm install
```

### 3. Open the project
Open the **`mobile/android`** folder specifically (not `mobile` itself) as an
existing project in Android Studio. It will detect the Gradle wrapper
(already included), auto-download Gradle 8.8 on first sync, and prompt you
to select an SDK location (writes `android/local.properties`, already
gitignored).

### 4. Start Metro in a separate terminal
```bash
cd mobile
npm start
```

### 5. Run on the emulator
In Android Studio: pick your AVD and click **Run** (▶), or from the command line:
```bash
npm run android
```

## iOS — run it in Xcode

### 1. Prerequisites (one-time, on your Mac — Xcode is macOS-only)
- **Xcode** (latest stable from the App Store)
- **CocoaPods**, installed via Bundler (recommended — this project ships a
  `Gemfile` pinning known-good CocoaPods/Ruby-gem versions):
  ```bash
  cd mobile
  bundle install
  ```
- **Node.js 18+**

### 2. Install JS dependencies and CocoaPods
```bash
cd mobile
npm install
bundle exec pod install --project-directory=ios
```
This generates `ios/CarServiceTracker.xcworkspace` and `ios/Pods/` (both
gitignored — regenerated by this command, never commit them). Autolinking
picks up the native iOS code for `react-native-safe-area-context`,
`react-native-screens`, `react-native-mmkv`, and `@react-navigation`
automatically from `package.json` — no manual Podfile entries needed for
any of them.

### 3. Open the workspace (not the .xcodeproj)
```bash
open ios/CarServiceTracker.xcworkspace
```
**Important:** once you've run `pod install`, always open the `.xcworkspace`
file, not `CarServiceTracker.xcodeproj` directly — the workspace is what
wires in the CocoaPods dependencies.

### 4. Start Metro in a separate terminal
```bash
cd mobile
npm start
```

### 5. Run on the Simulator
In Xcode: pick a simulator (e.g. iPhone 15) from the scheme dropdown and
click **Run** (▶), or from the command line:
```bash
npm run ios
```

## Connecting to the backend from the simulator/emulator

- **Android emulator → host machine:** `localhost` inside the emulator
  refers to the emulator itself, not your computer — use
  `http://10.0.2.2:8080` instead (already the default in
  `src/services/api.ts`)
- **iOS Simulator → host machine:** the iOS Simulator shares your Mac's
  network directly, so `http://localhost:8080` works as-is — if you're
  testing iOS, override `API_BASE_URL` back to `localhost` (see the comment
  in `src/services/api.ts`)
- **Physical device (either platform), same Wi-Fi:** use your computer's LAN IP, e.g. `http://192.168.1.23:8080`
- **If your services run on Kubernetes** (see `../k8s/README.md`) via `kubectl port-forward`, the same rules apply to whichever local port you forwarded to
